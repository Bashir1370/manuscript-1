# Current project objective: shared neuropathy transcriptional programs

## Central question

Does the DRG activate a common transcriptional injury program across different neuropathy conditions, and where does oxaliplatin-induced peripheral neuropathy (OIPN) fit within this spectrum?

## Current revision direction

The manuscript revision will be organized around the hypothesis that OIPN should be interpreted in the context of conserved and divergent molecular responses across different neuropathy models rather than focusing on a single isolated pathway.

The main comparison framework is:

- OIPN (oxaliplatin-induced peripheral neuropathy)
- CCI (chronic constriction injury)
- NC (nerve compression)

The goal is to identify:

1. Shared DRG transcriptional programs associated with neuropathic injury.
2. Biological pathways conserved across different injury models.
3. Molecular responses that distinguish OIPN from physical nerve injury models.

All subsequent analyses, interpretation, and manuscript revision should be aligned with this central question.
