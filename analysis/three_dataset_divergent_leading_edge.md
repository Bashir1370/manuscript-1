# Opposite-direction Hallmarks: three-study leading-edge follow-up

This analysis follows the existing Fig2 opposite-NES panel; it does not rerun GSEA or select pathways by significance. Source commit: `b7692076a6975aaf4adf1f0fecb163d5b4359e17`.

## Selection and evidence

The complete 50-Hallmark table identifies seven pathways whose OIPN NES sign opposes both NC and CCI. Script 07 requires Fig2_direction_selection.csv to match that exact selection and verifies NES and pathway FDR against the original GSEA files.

For each pathway, take the union of original leading-edge symbols from the three studies. Membership in all three leading edges is not required. Retrieve original differential-expression log2FC and genome-wide adjusted P values for the representative that entered each original GSEA rank; verify reconstructed representatives against ranked_statistics.csv. Absent rank symbols remain unavailable, not zero or nonsignificant.

The opposite-direction gene filter requires an available rank in all three studies and either OIPN log2FC > 0 with NC and CCI log2FC < 0, or the reverse. Gene signs are evaluated separately from pathway NES; the OIPN_matches_pathway_direction column records agreement without adding a selection requirement.

Prioritization additionally requires original gene FDR < 0.05 in OIPN and at least one of NC or CCI. Preserve a stricter all-three-significant subset. No fold-change magnitude cutoff or restricted-family FDR recalculation is applied.

## Interpretation limits

These are exploratory opposite-direction observations across the sampled cohorts, not proof of OIPN specificity or a formal model-by-injury interaction. Each study estimates neuropathy versus its own control. Different significance statuses do not establish significant differences between studies. Pathway and gene FDR are different testing levels; pathway selection here is based only on NES direction. No selected pathway is significant in all three studies, and individual pathway FDR remains archived for interpretation.

Leading-edge membership from a negatively enriched pathway is preserved as supplied by original GSEA. Unions permit comparison without requiring a gene to drive enrichment in all studies. The prioritized list mixes positive and negative OIPN directions; separate STRING input files support direction-aware follow-up.

GSE126773 remains excluded according to the existing three-study protocol; four-study analyses remain the sensitivity archive. This cohort choice and the exploratory selection must be reported in the manuscript.

## Reproduction

Run from the three-study repository root:

```r
Sys.unsetenv("DIVERGENT_LE_TABLES_ONLY")
source("scripts/cross_model/07_three_dataset_divergent_leading_edge.R")
```

The complete script creates tables, seven gene log2FC heatmaps in PDF/PNG, input MD5 checksums and R session information in `results/divergent_Hallmark_leading_edge_three_dataset`. Plots use raw gene log2FC, with a common linear display scale clipped at +/-6 (configurable with LE_COLOR_LIMIT) and stars for original gene FDR < 0.05; full values remain in CSVs. There is no row scaling. Each plot contains all direction-opposed genes, rather than only significant genes.

To regenerate tables without plots, set `Sys.setenv(DIVERGENT_LE_TABLES_ONLY="true")`. The script requires base R plus ggplot2 for plotting.

Archived tables were reconstructed from repository CSVs and independently checked; R execution and rendering have not been performed in this environment. Running the script locally provides that verification. `source_git_blobs.csv` records source Git blob hashes; runtime `input_checksums.csv` is generated by R rather than fabricated.
